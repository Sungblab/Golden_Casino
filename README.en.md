# Golden Casino Platform

This repository now contains the React and PostgreSQL based Golden Casino platform. The original Vanilla JS and MongoDB implementation is preserved under [`reference/legacy`](./reference/legacy).

The current milestone implements a real vertical slice: login, lobby, limit-based baccarat rooms, server-authoritative automated rounds, and ledger-backed wagering and settlement.

See [README.md](./README.md) for local commands and [docs/architecture.md](./docs/architecture.md) for the architecture.
