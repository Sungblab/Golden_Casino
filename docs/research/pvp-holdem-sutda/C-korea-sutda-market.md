# C. 국내 섯다 게임 시장 리서치

- 조사일: 2026-09-18
- 방법: 한국어 웹 검색 약 30회 + 공식 게임가이드(한게임 PC/모바일, 피망 섯다 공식 룰 문서 `dl.sudda.pmang.cloud/gamerule/*.md`, 한게임포커 LA섯다 가이드, 윈조이 사이트맵), 앱스토어/원스토어/서드파티 스토어 페이지, 언론 기사, 법령 정보(찾기쉬운 생활법령정보), 커뮤니티(디시인사이드) 페이지 직접 fetch.
- 표기 규칙: **(추정)** = 근거는 있으나 공식 확인 못 함 / **미확인** = 자료를 못 찾음 / **[나무위키]** = 비공식 위키 근거(오류 가능) / 따옴표는 원문 인용.
- 요약 (5줄):
  1. 국내 온라인 섯다는 사실상 **한게임(NHN)** 과 **피망(네오위즈)** 양강이며, 넷마블 계열은 2020년 PC 채널링을 종료하고 자회사 잼팟의 **윈조이** 브랜드 PC 섯다만 남았다(모바일 윈조이 포커에는 섯다 없음).
  2. 두 회사 모두 **2장 섯다 + 3장(초이스) 섯다** 가 기본이고, 한게임 모바일만 홀덤 섯다·섯둑이·배짱승부 등 변형이 많다. 6매/천장 섯다는 어느 상용 제품에서도 확인되지 않았다.
  3. 규칙 세칙(특수패 미발동 처리, 재경기 범위, 땡값)은 회사마다 다르지만 **공식 가이드에 명문화** 되어 있고, UI(족보 네비게이션·승률 표시)가 이를 실시간으로 보여준다.
  4. 베팅은 삥/따당/쿼터/하프/(풀·맥스)/콜/체크/다이 체계 + **첫 베팅 라운드 제한(하프-콜/하프-다이, 111~444)** + **판당 개인 베팅 상한** 이 공통 패턴이다.
  5. 규제(게임산업법 시행령 별표2)는 2026-02-03부터 **월 구매한도 100만원**, 1회 게임 사용한도는 월 한도 지급총량의 10%, 자동 베팅 금지, 상대 선택 금지(소액·무료머니 예외), 연 1회 본인확인이며, 이것이 채널 상한·자동 매칭·자동콜 부재 등 국내 섯다 설계를 직접 규정한다.

## C7. 우리가 참고할 만한 패턴 TOP 10 (근거와 함께)

우리 제품 전제: 2장 섯다, 화투 20장, PvP, 팟 에스크로 + 레이크.

1. **첫 베팅 라운드 제한 룰을 방 옵션으로 제공** — 피망 "하프-콜"(첫 베팅 하프/콜/다이만)·"하프-다이"(하프/다이만), 한게임 PC 111~444(앞 N명 하프·다이만), 한게임 모바일 '선만 하프·다이'. 효과: 첫 라운드 팟 폭주 억제 + 선의 부담 완화 + 판별 리듬 통일. 2장 섯다에서 1장→베팅→1장 구조(피망·리얼 섯다)를 쓰면 1구/2구 베팅에 각각 룰을 걸 수 있다.
2. **족보 네비게이션 + 실시간 승률 + 완성 족보 하이라이트** — 피망 Room.md: 강한 순 정렬, 특수족보 4종 포함, 패 2장 받으면 완성 족보 하이라이트, 화투 좌상단 월 숫자 표기, 족보별 승률 표시. 한게임 PC '족보도우미'(내 패 보라색 강조). 초보 진입 장벽 해소의 표준 UX.
3. **특수패 미발동·재경기 세칙의 명문화와 UI 노출** — 땡잡이 미발동 → 망통(한게임·피망), 암행어사 미발동 → 1끗, 구사·멍텅구리구사 미발동 → 3끗(피망), 구사 재경기는 '알리 이하'·멍텅구리는 '9땡 이하'(한게임·피망 공통), 13/18광땡 동률. 한게임포커 LA섯다는 "다이 유저도 추가금(판돈에 비례)을 지불한 후 재경기 참여"와 "구사를 이기는 족보가 있으면 재경기 없이 승리"를 명시. 우리 엔진의 재경기·비김 분기와 UI 문구를 이 세칙에 맞추면 국내 유저 기대치와 일치한다.
4. **땡값(보너스 팟)** — 두 모델: 피망 비율형(38광땡 +50%, 13/18광땡 +30%, 장땡 +20%, 1~9땡 +10%, 대상은 승자보다 낮은 족보로 끝까지 따라온 사람; 땡끼리 없음, 올인 시 없음, 판 상한 포함) vs 한게임 배수형(땡값+: 38광땡 2배, 광땡 1배, 땡 0.5배 of 각자 베팅액, 방 옵션). 에스크로 정산 시 "패자별 추가 차감"으로 구현 가능하고, 상한·올인 예외를 반드시 같이 설계해야 한다.
5. **판당 개인 베팅 상한과 '풀' 버튼 전환** — 한게임 PC 60억냥/1인/판(땡값 합산), 피망 50조/판 + 스택머니 반입 30조 제한, LA섯다 55억(친구방 2.75억). 상한에 닿으면 하프 대신 '풀(남은 한도)'이 뜨는 UX. 국내 1회 사용한도 규제 대응이자, 에스크로 최대 노출액을 결정론적으로 만든다.
6. **레이크를 재분배 이벤트 재원으로** — 한게임 '땡팟'(딜러비 일부 적립 → 5인/4인 전원 땡 시 분배, 히든 땡팟), 피망 '광땡 잭팟'(1,000만 이상 방, 38광땡 승리 시 누적액 비율 지급) 및 거점전 점령 동호회에 딜러비 일부 분배. 레이크(5%; 자유방 7%)의 일부를 잭팟 풀로 돌리면 레이크 거부감을 낮추고 고족보 순간의 보상을 키운다.
7. **파산 방지 루프(무료 리필·보험·방 내 자동 리필)** — 한게임 무료충전 30만냥×10회 + 등급보험(등급 상승 시 적립, 올인 시 자동 지급) + 판돈 3만 방 올인 시 1,000만 자동 리필(1일 5회); 피망 500만 미만 시 50억×8회 + 보험금 5단계(누적 7,800억); 리얼 섯다 200만×20회. 무료머니 판은 미션·랭킹 집계에서 제외(피망)해 어뷰징을 막는 것이 세트.
8. **보유머니 구간 채널 + 자동 매칭 + 방 정보 투명화** — 피망 채널: 갑오(삥 2,000만~5,000만)·알리(2억~20억)·장땡(100억~500억)·광땡(2,000억)·타짜(1조)·자유·친구대전(200만), 각 채널 최소/최대 입장 머니, 딜러비 5% 동일; 로비에서 채널만 고르면 "자동으로 최적의 게임 상대"를 찾고 없으면 방 자동 생성. 방 정보에 게임룰·삥값·플레이 판수·참여 인원·최근 5판 평균 팟·최근 승리 족보 노출, 유저 영역에 보스(선)/클래스/방장/아이템/프로필 아이콘. 한게임 PC는 등급(중수~신)별 8개 경기장(자유 3,000냥 ~ 타짜 1,000만냥).
9. **리텐션 메타: 시즌 리그 + 동호회/거점전 + 주간 토너먼트 + 친선대전** — 피망 랭킹 페스타(RP = 승리 획득·패배 손실의 일부 → 페스타1~3 리그 승강, 랭킹샵), 동호회(창단은 페스타1 이상, 10명 미만 미분배·15명 미만 50%), 거점전(화~수 신청, 금~일 진행, 월 정산, 3인 이상 삥 베팅 판만 집계, 피크타임 보너스), 친구 선물(일 10명, 내 재화 비차감), 친구 초대 보상; 한게임 주간 토너먼트(1시간, 3분마다 판돈 상승, 부활 3회, 50위 상금), 주간 랭킹전, 친선대전(닉네임 검색·즐겨찾기·보이스톡). 우리 PvP 룸에 '친구방 + 소액 삥'과 시즌 포인트를 얹는 것이 가장 비용 대비 효과가 큼.
10. **신뢰·안전 UX를 게임 안에 내장** — 피망: GLI RNG 인증·GUCC 인증 페이지, 폴리스 처벌 기준(현금거래·다중계정·불법 프로그램 1년 제한) 공개, 셀프케어(이용시간/구매/손실 한도), 실시간 셔플 문구; 한게임: 게임화면 신고 버튼, RNG/이용자보호 인증 메뉴; 리얼 섯다: 자가 한도·강퇴 투표·시간 초과 자동 다이. 리뷰의 최대 불만이 "조작·티밍"이므로, 셔플 커밋(해시)·판별 로그·티밍 신고 흐름을 눈에 보이게 만드는 것이 국내 제품 대비 차별화 지점이다.

보너스 관찰: (a) 한게임 모바일 '홀덤 섯다'(손패 2 + 공유 1, 3라운드, 최대 7인, 18광땡>13광땡)와 '배짱승부'(패 미공개 블라인드 하프)는 2장 섯다 엔진에 옵션으로 얹기 쉬운 변형이다. (b) 3장 초이스는 땡 확률을 3배로 올려(5.3%→15.8%) 고족보 빈도를 높이는 검증된 변형이다. (c) 단축키(콜 7·삥 4·다이 8·체크 5·따당 1·하프 0)는 PC 웹 UX에 바로 적용 가능하다.
