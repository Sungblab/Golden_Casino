# F. 보조 슬라이스 (메인 에이전트 직접 조사, 2026-09-18)

## F1. 포커 UI 디자인 케이스 스터디에서 건질 것

- **한 손 조작이 기본**: 모바일 포커 세션의 약 63%가 한 손 사용이라는 조사(2021, SparkTime 인용)를 근거로, 액션 버튼을 엄지 도달 범위(하단)에 두고 베팅 슬라이더 대신 **탭 증감(프리셋)** 으로 옮기는 흐름. 우리 v4 레일(모바일 하단 바, 원탭 프리셋)과 같은 방향. (출처: sparktime.co.uk/developing-mobile-first-poker-apps)
- **가로·세로 둘 다 1급 시민**: Limeup의 Poker House 리디자인은 기존 세로 전용 앱에 가로 모드를 추가하고, 아바타/감정 표현·채팅·토너먼트 순위 구조·레벨 보상·룰렛 보너스를 함께 넣음. 즉 "테이블 화면"만이 아니라 리텐션 레이어(보상·순위·소셜)를 리디자인 범위에 포함. (출처: limeup.io/projects/poker-house)
- **정보 위계**: ux.bet 가이드는 로비→테이블 전 구간의 브레이크포인트·제스처 정의, 책임 게임 요소(시간 알림, 한도, 자기제한) 내장, 테마·사운드 같은 사용자 설정 제공을 표준으로 봄. 구체적 버튼 배치 지침은 없음. (출처: ux.bet/poker)
- **"적응형 레이아웃"(공격적 유저에겐 슬라이더 빠르게, 신중한 유저에겐 정보 패널) 으로 만족도 29%↑, 세션 18→32분** 같은 수치는 벤더 블로그의 주장이라 (추정)으로만 취급.

## F2. 튜토리얼 · 연습(봇) 모드 사례

| 제품 | 형태 | 비고 |
|---|---|---|
| Poker Power 앱 | 레슨과 짝지어진 초보용 봇 테이블 | 레슨에서 배운 액션(콜/레이즈/체크/폴드)을 봇 상대로 바로 연습 |
| Learn Poker Offline – Hold'em (iOS) | 오프라인 봇 대전 | 초보~숙련 난이도 봇 |
| 3UP Gaming | "First 5 Hands coaching mode" | 첫 5핸드 동안 코칭 오버레이 (벤더 주장) |
| Poker Patio | 브라우저 싱글플레이 봇 테이블 | 무료 웹 |
| Governor of Poker 3 | 사실상 봇 중심 싱글/멀티 혼합 | 소셜 포커의 대표적 봇 활용 사례 |
| 한게임 싱글 맞고 | 데이터 없이 되는 오프라인 AI 대전 (NHN) | 웹보드 장르에서 "싱글 AI 모드"를 별도 앱으로 낸 사례 |
| 한게임 섯다&맞고 | 튜토리얼 + 플레이 화면에 족보 상시 노출 | 상세는 C 보고서 참조 |

함의: 로드맵의 "튜토리얼 모드(봇 상대 연습 판)"는 업계에서 검증된 패턴. 단, **봇은 연습 테이블에만, 명시적으로 표시**해야 함 — 실전 테이블에 봇을 섞으면 신뢰 문제로 직결(F3 참고).

## F3. 소규모 유저 풀에서 테이블을 채우는 방법 (승인제·소규모 플랫폼에 특히 중요)

- **봇으로 좌석 채우기는 평판 리스크**: Zynga Poker는 2018 Q4 실적 발표에서 봇 문제를 주요 이슈로 언급했고, 유저 포럼에는 "낮은 랭크 계정이 들어와서 핸드도 안 하고 나간다"는 불만이 반복. Governor of Poker 3, Pokerist 리뷰에도 봇 의혹 다수. (출처: raketherake.com 2019/04, Google Play 리뷰)
- **온디맨드 싯앤고(좌석이 차면 즉시 시작)**, **헤즈업 SNG(2명)**, **터보/하이퍼 블라인드** — 적은 인원으로도 게임이 성립하고 30분 안에 끝나는 형식. 캐시게임 대기보다 이탈이 적음. (출처: cardplayer.com, pokerrrrapp.com, bettoblock.com)
- **정해진 시간에 몰아넣기**: 스케줄 토너먼트는 유저를 특정 시각에 집중시킴. 소규모 풀에서는 "매일 저녁 9시 홀덤 토너먼트" 같은 고정 슬롯이 상시 캐시 테이블보다 현실적.
- **프라이빗 클럽 패턴(PokerStars Home Games)**: 클럽 이름 + 초대 코드로만 입장, 관리자 지정·멤버 관리, 클럽 내 캐시·토너먼트를 아무 때나 개설, 클럽 통계(결과·포인트·녹아웃·리더보드)와 시즌 길이 설정. 승인제 폐쇄형 플랫폼인 우리와 구조적으로 가장 잘 맞는 참조 모델. (출처: pokerstars.com/poker/home-games, pokernews.com 2020/06)
- **큰 사이트도 네트워크로 유동성을 합침**(iPoker 등 공유 풀). 우리는 단일 풀이므로 "빈 테이블 = 이탈"을 막는 UX(대기 중 알림, 좌석 차면 푸시, 로비에서 인원 수 실시간 표시)가 대체재.
