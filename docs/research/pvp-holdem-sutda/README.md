# PvP 홀덤·섯다 리서치 — 현재 구현 × 국내외 시장 (2026-09-18)

> 목적: 홀덤과 섯다를 개선하기 전에 "지금 우리가 어디에 있고, 시장 표준이 무엇이며, 무엇부터 고쳐야 하는가"를 한 문서로 고정한다.
> 방법: 코드 정독(읽기 전용) 2건 + 웹 리서치 3건(국내 홀덤·국내 섯다·해외 홀덤)을 병렬로 수행하고, 치명 버그 후보는 메인 세션이 코드로 재검증했다. 상세 근거(파일:줄, URL)는 `docs/research/pvp-holdem-sutda/` 아래 부록 A~G에 있다.
> 표기: 확인된 사실은 그대로, 추정은 "(추정)", 확인 실패는 "미확인". 시장 수치는 2026-09-18 기준이며 빨리 바뀐다.

## 0. 한눈에 보기

1. **홀덤 쇼다운 정산이 망가져 있다(코드로 확정).** 홀카드가 DB에 저장되지 않아 정산이 보드 5장만으로 족보를 비교하고, 그 결과 모든 쇼다운이 무승부 분할로 끝난다. 어떤 개선보다 먼저 고쳐야 하고, 최근 커밋의 "무승부 라벨 수정"은 증상만 다룬 것이다. (§2.3, 부록 G)
2. **홀덤은 "핸드가 돌아가는" 수준의 최소 구현이다.** 6-max 노리밋 캐시, 20초 고정 타이머, 바이인 없음(좌석 스택 = 지갑 전액), 타임뱅크·프리액션·핸드 히스토리·자리 비움·BB 대기 전부 없음. 해외 표준 필수 항목 19개 중 충족은 4개 안팎. (§4.1)
3. **섯다는 2장 섯다의 뼈대만 있다.** 액션이 다이/체크/콜/하프 4개뿐(삥·따당·쿼터·풀 없음), 구사 재경기 없음, 멍텅구리 구사 재경기가 "판돈 이월·재딜"이 아니라 "팟 균등 분할 후 종료"로 구현되어 도움말과도 어긋난다. 대기 중 이탈 좌석 미회수로 테이블이 잠기는 버그가 있다. (§2.2, §2.3)
4. **국내 홀덤은 두 트랙이다.** 한국식 캐주얼(한게임 홀덤 5인·삥/쿼터/하프/풀 프리셋)과 TDA 정통 노리밋(로얄홀덤·피망 쇼다운·WPL·2ACE: 6/9-max, 매일 토너먼트·6인 즉시 SNG·오프라인 새틀라이트). 정통 트랙의 매출과 리텐션은 캐시게임이 아니라 토너먼트가 만든다. (§3.1)
5. **어느 시장이든 1순위 불만은 확률·봇·몰아주기 의혹이다.** 운영사의 답은 늘 RNG 인증 배지인데 효과가 없다. 검증 가능한 핸드 히스토리·리플레이가 신뢰의 실질적 근거가 된다. 우리는 홀카드조차 저장하지 않아 사후 검증이 불가능한 상태다. (§3, §6)
6. **해외 표준 수치는 명확하다.** 액션 타이머 프리플랍 10초/포스트플랍 15초 + 자동 발동 타임뱅크, 프리셋 4개(프리플랍 BB 배수·포스트플랍 팟 %), 큰 베팅만 확인, Run It Twice, 무료 래빗헌트, 레이크 5%·캡 2~5BB·노플랍 노드랍. (§3.3)
7. **추천 순서: P0 정합성(버그·규칙) → P1 표준 패리티 → P2 형식 확장(SNG·섯다 액션 세트) → P3 소셜·메타.** 구체 백로그는 §7.
8. **섯다 시장은 한게임·피망 양강이고, 규칙 세칙(특수패 미발동 처리·재경기 범위·땡값)이 공식 가이드에 명문화되어 있다.** 우리 섯다의 세칙 불일치(§2.2)는 국내 유저가 바로 알아차릴 차이다. (§3.2)
9. **국내 웹보드 규제(게임산업법 시행령 별표2)는 실제 금전이 오가는 팟·레이크·환전 구조를 국내向 서비스로는 허용하지 않는다.** 게임머니 기반이어도 월 구매한도·1회 사용한도·자동 베팅 금지·상대 선택 금지가 적용 대상이며, 이는 설계 전제를 바꾸는 질문이라 §8에서 사용자 결정으로 남겼다. (§3.4)

### 2.1 홀덤 (부록 A)

### 2.2 섯다 (부록 B)

| 영역 | 현재 값 | 비고 |
|---|---|---|
| 형식 | 2장 섯다 고정, 화투 20장, 6석, 방 3개(Rookie 삥 1/상한 100, Standard 10/1,000, High Roller 50/5,000) | 3장·6매 없음 |
| 판돈 | `min_bet` = 앤티(전원 자동 납부), `max_bet` = 1인 1판 총 기여 상한 | 한게임 "1인 최대 베팅"과 같은 개념 |
| 액션 | 다이 / 체크 / 콜 / 하프(콜 + 팟 ½) — **4개뿐**. 삥(액션)·따당·쿼터·풀·올인 없음, 잔액 부족 시 다이만 | 하프 계산은 한게임 정의와 동일 |
| 진행 | 앤티 → 1장 딜 → 1차 베팅 → 2장째 딜 → 2차 베팅 → 쇼다운. 선은 시계방향 로테이션, 선이 마지막 행동. **매 판 전원 재준비 필요**(UI 문구 "자동 참여"와 모순), 판 사이 휴식 없음 | 1차 베팅은 전원 체크로 넘어갈 수 있음 |
| 족보 | 38광땡 > 18=13광땡 > 장땡~삥땡 > 알리·독사·구삥·장삥·장사·세륙 > 갑오~1끗 > 망통. 표준과 일치 | 참고 데이터·강도 계산·"노려볼 패" 있음 |
| 특수패 | 땡잡이(3·7)·암행어사(4·7) 표준과 일치. **구사(4띠·9띠) 미구현**, 멍텅구리 구사는 장땡이 있으면 재경기 불성립(표준은 광땡만 차단) | |
| 재경기 | `redeal`이면 생존자 전원을 승자로 **팟 균등 분할 후 판 종료**(다이한 사람 앤티까지 분배, 레이크 0). 표준은 판돈 이월 + 새 패. 도움말 "낸 돈을 모두 돌려받아요"와 불일치, 정산 라벨은 lose로 기록 | 클라이언트 재경기 배너 분기는 도달 불가 |
| 타이밍·이탈 | 20초 고정(만료 시 체크/다이), 타임뱅크 없음. 판 중 자리 비우기는 즉시 다이. **대기 중 이탈 좌석이 회수되지 않아 테이블 잠김** | 재시작 시 무조건 환불 |
| 레이크 | 홀덤 `rakeFor` 재사용(5%, 상한 `max_bet`의 3%). 기권승에도 부과 | 도움말에 비율 미기재 |
| 클라이언트 | 홀덤 v4 셸·CSS 재사용, 3버튼(다이/체크·콜/하프), 족보 패널·강도 미터·노려볼 패, 선 배지, 세로 모드, 도움말 시트, 화투 PNG + 월 숫자 배지, 딜 애니메이션 | 쇼다운 뒤집기·쪼기 연출 없음, 사운드는 바카라용 TTS("베팅이 마감됐습니다", "Fold") |
| 없는 것 | 삥·따당·쿼터·풀, 자동 콜/다이 예약, 올인·사이드팟, 판 히스토리, 전적(게임 히스토리·관리자 통계 API에서 섯다 누락), 위너 피드, 아바타·이모티콘·랭킹·미션 | §4.2 매트릭스 |

### 3.2 국내 섯다 (부록 C)

**양강 구도.** 한게임(NHN, PC+모바일 '섯다&맞고', 2017-03 모바일 출시)과 피망(네오위즈, PC+모바일+for Kakao)이 사실상 시장을 양분한다. 넷마블은 2020년 PC 채널링을 종료했고 자회사 잼팟의 윈조이 PC 섯다만 남았다(모바일 윈조이 포커엔 섯다 없음). 소규모 앱(리얼 섯다 등)은 평점·평판이 낮다.

**규칙 세칙이 우리와 다르다.** 공식 가이드에 명문화된 값:

**국내 제품의 실제 대응(관찰).**
- 판당 개인 베팅 상한(한게임 60억냥, 피망 50조)은 1회 사용한도를 각사 머니 단가로 환산한 값으로 보인다(추정).
- 피망은 방 만들기·상대 선택 자체를 없애고 자동 매칭 전용으로 운영해 "상대 선택 금지"를 구조적으로 우회한다. 소액 친구방(피망 200만, 리얼 섯다 "선택 채널")은 0.5% 예외를 활용한 것으로 보인다(추정).
- 자동 콜/다이 예약이 국내 어느 제품에도 없는 것은 "자동 베팅 금지" 조항과 직접 관련된다(추정이 아니라 조항 문언과 정확히 일치).
- 무료 게임머니는 구매한도 산정에서 빠지므로, 무료 리필·보험을 파산 방지 겸 리텐션 장치로 적극 활용한다.

**우리 제품에 대한 함의(질문으로 이관, §8-5).** 한국 이용자 대상이라면 게임머니 기반이어도 위 전 항목이 적용 대상이고, 실제 금전이 오가는 팟·레이크·환전 구조는 국내 서비스로는 사행성 게임물 규제에 저촉될 가능성이 크다. 해외 전용이라면 법적 제약은 아니지만, 국내 유저가 기대하는 UX 관례(첫 베팅 제한, 족보 네비게이션, 땡값)는 규제와 무관하게 여전히 유효하다.

### 3.5 보조 관찰 (부록 F)

- 모바일 포커 세션의 대다수가 한 손 조작이라는 조사(2021)를 근거로 업계가 슬라이더 대신 탭 프리셋으로 이동했다. 우리 v4 레일과 같은 방향.
- 연습(봇) 모드는 검증된 패턴(Poker Power, Learn Poker Offline, 한게임 싱글 맞고). 단 봇은 연습 테이블에만, 명시적으로 표시. 실전 테이블의 봇 의혹은 Zynga가 실적 발표에서 다룰 정도의 평판 리스크.
- 소규모 유저 풀 대응: 온디맨드 SNG(좌석이 차면 즉시), 헤즈업 SNG, 정해진 시간의 스케줄 토너먼트, PokerStars Home Games식 프라이빗 클럽(초대 코드·클럽 통계·시즌). 승인제 폐쇄 플랫폼인 우리와 구조가 맞는다.

## 5. 갭 분석

### 5.1 패리티가 필요한 것 (없으면 "안 되는 게임"으로 읽힘)

- 홀덤: 정확한 쇼다운 정산(H1), 바이인·테이블 스택, 프리플랍/포스트플랍 분리 타이머 + 타임뱅크, 프리액션, 자리 비움·BB 대기·데드 블라인드·미준비자 타임아웃, 접속 끊김 유예, 폴드 승 비공개·머크, 노플랍 노드랍, 핸드 히스토리(카드·액션)와 리플레이, BB 표기 토글, 슬라이더 또는 직접 입력, 올인 승률 표시.
- 섯다: 테이블 잠김(S1)·루프(S2) 수정, 표준 액션 세트(삥·따당·쿼터·하프·풀), 첫 베팅 라운드 제한 옵션, 구사·멍텅구리 구사 재경기(판돈 이월 + 재딜, 범위를 표준에 맞춤), 잔액 부족 시 올인, 판 사이 자동 진행, 전적·히스토리 API 연동, 섯다 전용 사운드.

### 5.2 차별화 후보 (우리가 이미 앞서 있거나, 작은 비용으로 앞설 수 있는 것)

- 실시간 족보·드로우·강도 패널과 "노려볼 패"는 국내외 어디에도 흔치 않다(Zynga HSM, Lipoker 정도). 초보 친화 포지셔닝의 핵심 자산.
- 세로 모드·도움말 시트·한 줄 액션 설명은 이미 정통 트랙의 칭찬 포인트(쇼다운)와 같은 축.
- 웹 기반이라 PC 핫키·금액 직접 입력·링크 초대(PokerNow식)를 싸게 붙일 수 있다.
- 레이크 상한이 낮다(Micro 3코인). 로비에 "레이크 5%·상한 N"을 표기하면 WPL 5.5%·SNG 9.1% 대비 비교우위.
- 검증 가능한 기록(핸드 히스토리·리플레이·필요 시 셔플 커밋-리빌)을 1순위 정보 기능으로 두면 "RNG 배지"보다 강한 신뢰 신호.

### 5.3 하지 말아야 할 것

- 실전 테이블 봇 채우기(평판 리스크), 유료 타임뱅크(GG 비판), 프리플랍 팟 레이크(GG 비판), 무제한 리바인 토너(쇼다운 1점 리뷰 원인), 이모지·던지기가 카드·액션 레일을 가리는 레이어(ClubGG 불만), 업데이트로 사용자 프리셋 저장값 삭제(WPL 불만).

## 6. 기회와 위협

**기회**
- 국내 정통 트랙은 토너먼트 중심이라 "6인 즉시 SNG"만 붙여도 형식 격차가 크게 준다. 우리 6-max 엔진과 규격이 같다.
- 승인제 폐쇄 플랫폼은 프라이빗 클럽(Home Games) 모델과 궁합이 좋다: 초대 코드 방, 클럽 리더보드·시즌, 정해진 시간의 토너먼트로 적은 인원을 모은다.
- 초보 친화 자산(족보 패널·도움말·세로 모드)은 "무료 연습장" 포지셔닝과 홀덤펍 유입층에 맞는다.

**위협**
- H1이 그대로면 유저가 첫 쇼다운에서 "실력과 무관하게 항상 찹"을 경험한다. 어떤 UX 개선도 무의미해진다.
- 스택 = 지갑 전액 구조는 한 핸드에 전 재산이 걸리고 상대에게 잔액이 노출된다. 규제·신뢰·리스크 관리 모두에서 불리하다.
- 홀카드·액션 미저장은 담합·봇 의혹이 나왔을 때 반박 수단이 없다는 뜻이다.
- 룸매니저 5개가 공통 베이스 없이 복제되어 있어(부록 A2, B2) 타임뱅크·자리 비움·액션 로그를 넣을 때 홀덤·섯다에 두 번 구현하게 된다.

## 8. 사용자 결정이 필요한 질문

1. **홀덤 바이인 모델**: 지갑 = 스택을 유지할지, 방별 바이인(예: 40~100BB)과 리바이로 갈지. 규제·리스크·UX 모두 후자를 가리키지만 원장 구조 변경이 크다.
2. **섯다 규칙 세트**: 한게임식(콜·삥·다이·체크·따당·하프·풀 + 베팅룰) vs LA섯다식(쿼터·맥스 추가, 삥·체크는 보스만) 중 무엇을 기준으로 할지. 재경기는 "판돈 이월 + 재딜"로 갈지.
3. **멍텅구리 구사 차단 범위**: 현재(장땡 차단)를 유지할지 표준(광땡만 차단)으로 바꿀지. 테스트가 현재 동작을 고정하고 있어 의도적 선택일 수 있다.
4. **토너먼트/SNG 우선순위**: 캐시게임 패리티(P1)를 끝낸 뒤 SNG를 할지, SNG를 앞당겨 유저 풀 문제를 먼저 풀지.
5. **규제 준수 정책**: 국내 웹보드 규제(§3.4 — 월 구매한도 100만원, 1회 사용한도 10%, 상대 선택·자동 베팅 금지)를 설계 제약으로 채택할지 여부. 채택하면 로비·매칭·프리액션 설계가 바뀐다(예: 자동 콜/다이 예약을 P1-3에서 제외해야 할 수 있음). 서비스 대상(국내/해외)이 먼저 정해져야 답할 수 있다.
6. **공통 PvP 베이스 리팩터링**: P1을 두 게임에 각각 넣을지, 먼저 공통 베이스를 뽑을지(과거에 미룬 결정, 메모리 `room-engine-refactor-before-new-games`).
