## E8. 우리가 참고할 만한 UX 패턴 TOP 15 (브라우저 6-max NLHE 캐시게임 기준)

1. **프리플랍/포스트플랍 분리 타이머 + 타임뱅크 자동 발동** — PokerStars 10초/15초, 타임뱅크 15초에서 10핸드마다 +5초, 최대 30/60초로 상한. 팟에 돈이 걸렸을 때만 자동 발동하고, 아니면 폴드+sit out. 핸드/시간당 처리량 9% 증가라는 근거가 있고, PokerNow 유저도 "프리플랍만 짧게"를 요청함. [S2][S3][S65]
2. **타임뱅크를 "카드 N장 × 30초"로 시각화** — GGPoker Time Bank Card(무료 3장, 카드당 30초)는 남은 여유를 한눈에 보여 주고 소진 시점을 예측 가능하게 함. 유료 구매(1BB)는 논란이 크므로 배제하고 무료 카드 + 핸드당 충전만 채택 권장. [S20][S21][S22]
3. **프리셋 베팅 버튼 4개 × (프리플랍 BB 배수 / 포스트플랍 팟 %) + 사용자 편집** — PokerStars 표준(최대 4개, 커스텀 값), GG 모바일 기본 1/3·1/2·3/4·팟. PokerNow 피드백에도 "1/3팟 추가", "% 커스텀" 요청이 있음. 최종 금액은 항상 "Raise to X"로 표기. [S7][S8][S28][S66][S59b]
4. **큰 베팅/올인은 확인 옵션, 나머지는 원탭** — GGPoker는 설정에서 큰 베팅·올인 확인을 켤 수 있고, partypoker는 One-Click Custom Bet으로 즉시 실행. 기본 원탭 + "올인/팟 50% 초과 시 확인" 토글이 두 요구를 모두 만족. [S28][S36]
5. **체크 가능할 때 폴드 버튼 숨기기(또는 2차 확인)** — PokerStars가 초보 실수 방지를 위해 도입, 일부 프로 반발이 있었으므로 설정으로 끌 수 있게. [S16]
6. **레이즈·폴드 버튼 위치 고정 및 분리** — PokerNow 피드백 "레이즈 확인이 폴드와 같은 위치에 떠서 혼동". 액션 레일에서 파괴적 액션(폴드)은 항상 왼쪽, 확정(콜/레이즈)은 오른쪽 고정. [S66]
7. **프리액션 체크박스 세트 + 상황 바뀌면 자동 해제** — Check/Fold, Check, Call any, Fold to any(+ 사전 RIT 선택 요청 17표). 프리플랍에 레이즈가 들어오면 "Call"이 "Call X"로 갱신되거나 해제되는 PokerStars식 규칙. [S10][S66]
8. **BB 표기 토글은 아바타 탭으로, 올인 콜·1BB 미만이면 칩으로 자동 복귀** — PokerStars 규칙 그대로. 6-max 캐시에서 스택 깊이 판단이 빨라짐. [S9]
9. **올인 시 승률(에퀴티) 자동 표시 + Run It Twice 프롬프트** — PokerStars 설정, partypoker 모바일은 자동 표시. RIT는 양측 동의·가 걸린 사람만, 핫키/버튼으로 1회/2회 선택. [S8][S38][S30][S63]
10. **좌석은 랜덤 배정, 테이블만 선택** — GGPoker 방식(Table View로 테이블 선택, 좌석은 랜덤). 자리 선점(bumhunting)을 막고 UI가 단순해짐. Rush & Cash처럼 BB 최소 횟수 기준 배정은 패스트폴드용. PokerNow도 "늦게 온 사람 랜덤 좌석" 29표. [S33b][S66]
11. **입장 시 "BB 대기 / 지금 포스트" 선택 + 미스 블라인드 데드 처리 + 블라인드 3~4회 미스 시 자동 퇴장** — PokerStars/GG 공통. 캐시게임 좌석 회전과 공정성의 기본. [S10][S11][S6]
12. **오프라인/이탈 플레이어 즉시 폴드(또는 타임뱅크 소진 후 sit out) + hit-and-run 완화 장치** — PokerNow 최다 요청(56표)이자 GG/Stars가 10핸드 최소 규칙까지 도입한 이유. 벌칙형(차단)보다는 "N핸드 미만 이탈 시 다음 입장 쿨다운" 정도의 완화판 권장(레크 플레이어 반발 사례 참고). [S66][S33][S13][S33c]
13. **핸드 리플레이어 + 세션 원장 + 노트/컬러 태그** — 리얼머니 3사 공통, PokerNow 원장은 홈게임 신뢰의 핵심. 6-max에서는 8색(PokerStars)보다 4~5색이면 충분 **(추정)**. [S8][S25][S62]
14. **소셜 리액션은 "조건부·대상 한정·짧게"** — GG Splash는 50BB+ 큰 팟을 잃은 사람만, 그 상대에게만, 수 초 가림. ClubGG는 이모지가 홀카드를 가려 불만. 던지기/이모지는 카드·액션 레일을 절대 가리지 않는 레이어에, 상대 화면 방해 효과는 옵트아웃 가능하게. [S34][S35][S83]
15. **카드 스퀴즈/딜 애니메이션은 토글, 4색 덱·테마·사운드는 설정 1페이지** — GG는 Card Squeeze를 끄면 즉시 공개, EasyPoker는 길게 눌러 보기. 멀티테이블·빠른 플레이 유저는 끄고, 캐주얼 유저는 켬. [S39][S68]

보너스(정책·정보 계열): 레이크는 5%·캡 2~5BB·No Flop No Drop이 표준이며 GG만 프리플랍 3벳 팟에도 레이크를 걷어 비판받음 → 우리 팟 에스크로+레이크 모델도 프리플랍 종료 팟은 0% 권장 [S91][S91b]; 내장 HUD는 GG/888처럼 "전원에게 동일 정보"로 제공하면 3자 툴 금지 정책과 세트로 형평성 논거가 됨 [S25][S40].
